## RPCFree

We build blockchain RPC infrastructure.

Our free public endpoints are at **[rpcfree.com](https://rpcfree.com)** — JSON-RPC for Ethereum, Base, Polygon, and Arbitrum, with no signup or API key required. The same URL serves a documentation page when accessed in a browser and JSON-RPC responses when called by an application.

Paid plans and dedicated nodes are at **[etox.io](https://etox.io)**.

### Public endpoints

| Network | Chain ID | Endpoint |
|---|---|---|
| Ethereum Mainnet | 1 | `https://rpcfree.com/ethereum-rpc` |
| Base | 8453 | `https://rpcfree.com/base-rpc` |
| Polygon PoS | 137 | `https://rpcfree.com/polygon-rpc` |
| Arbitrum One | 42161 | `https://rpcfree.com/arbitrum-rpc` |

333,000 calls per day. Archive data included. Trace and debug methods supported.
